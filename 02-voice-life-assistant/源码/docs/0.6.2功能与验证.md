# 0.6.2 功能与验证

本版把原先固定“打开抖音”的入口改为按手机真实可启动应用的名称查找，并增加首次权限集中引导。保留视觉首页，以及硬件 WAV 本地转写、电话执行、本机记录和可选事件同步。

版本：`0.6.2`，`versionCode = 10`，应用包名 `cn.seniorvoice.demo`。交付文件使用 `语音生活助手_0.6.2_安卓安装包.apk` 和 `语音生活助手_0.6.2_完整测试版.zip`。

## 本版行为

| 场景 | 预期行为 |
|---|---|
| 第一次进入本版 | 打开集中引导；可申请基础权限、检查蓝牙、查看旧系统位置信息要求，也可跳过 |
| 集中申请权限 | 只申请硬件蓝牙及直接拨号必需权限；系统授权仍由用户或家人确认 |
| “打开 QQ / 启动微信 / 打开抖音” | 读取本机可启动应用名称，唯一匹配后请求系统启动；无需逐个录入包名 |
| 名称找不到 / 同名多个应用 | 显示原因并停止，不自动挑一个应用 |
| “给女儿打电话” | 从 App 内保存的联系人取号码；已授电话权限后直接请求拨打 |
| 硬件发 WAV | 手机收齐后用内置 Vosk 离线转文字，再进入同一指令流程；不向图片服务上传 WAV |
| 页面反馈 | 显示处理阶段、转写文字与结果，配合手机震动；不为每次明确操作再加 App 确认框 |
| 记录 | 先写本机 SQLite，配置独立事件接口后再异步同步；后端不可用不阻塞手机动作 |
| 首页 | 保留视觉设计，不增加“语音”“拍照”按钮 |

通过 `MAIN / LAUNCHER` 启动入口查询真实应用目录，不依赖每个应用一条硬编码命令。应用需已安装、对助手可见、有启用且可用的启动入口；目录名称与口头称呼不同、系统分身或其他用户资料中的应用，仍需现场验证。多个启动入口若属于同一软件，不据此当作多个同名软件；多个不同软件名称相同则不猜选。

匹配会规范空白、大小写和全半角；QQ 支持常用“扣扣”称呼。仍需先正确转写应用名，离线中文模型不能保证所有英文名称、口音或噪声下的识别。电话联系人按保存称呼匹配，不用近似姓名猜号码。

## 权限准备边界

Android 12 及以上申请蓝牙扫描 / 连接所需的附近设备权限；Android 11 及以下按系统规则申请 BLE 扫描所需位置权限。电话权限用于直接拨号，允许用户暂不授权。

一次集中发起申请可以减少来回找入口，系统仍可能分别显示询问。App 无法代替用户确认系统权限；拒绝后可跳过引导，永久拒绝时提供系统设置入口。蓝牙开关和旧系统位置信息开关可能另需用户确认。设置页保留重新打开引导的入口。

这条硬件语音流程不要求手机麦克风、通讯录或无障碍权限。NextAction 仍是独立、可选模块，它的屏幕采集与无障碍授权不属于本次基础权限引导；普通打开应用、电话指令不经过 AI 单步补全。

## 当前限制

测试时手机需解锁、助手在前台。打开其他软件后先返回助手，再发下一条语音。尚未实现后台 BLE 保活、锁屏启动其他应用或跨 App 连续代办的保证；“不在首页放语音按钮”不等于系统后台服务已完成。

本版实现的是启动应用和拨打 App 内联系人，尚未实现进入任意应用后自动给指定好友发消息、视频通话或连续操作。请求系统操作成功也不代表电话接通或后续任务完成。系统默认 SIM 选择及厂商提示不能由 App 统一消除。

图片问药、紧急按钮双击定位通知、硬件播报视觉答案、登录和异地多机查看尚未完成真实闭环。浏览器演示的模拟状态不作为真机功能验收依据。朋友的图片 `/analyze` 目前已知需要 `image + intent`，其响应不能假定包含药品答案；图片传输与结果回传需按 [后端接入清单](给视觉后端同学的接入清单.md) 确认。

## 真机验收顺序

1. 覆盖安装 0.6.2，确认资料保留、首次权限引导出现；允许或跳过后都能进入首页，并能从设置重新打开引导。
2. 允许基础权限，确认不会强制申请手机麦克风、通讯录、无障碍；检查拒绝、部分允许及到系统设置后返回的状态。
3. 先用原生文字测试打开已安装的 QQ、微信和其他应用，确认动态目录工作；对不存在的应用和同名软件停止并提示。
4. 保存测试联系人，用文字请求拨打，确认不多出 App 二次确认；拒绝电话权限时不拨号。使用可接听的测试号码。
5. 连接 ESP32，先验证 `ping / pong`，再发真实人声 WAV；核对接收、转写、应用名匹配 / 联系人查找、系统请求和记录各阶段。
6. 每次打开目标软件后返回助手再测下一条；另外检查识别途中离开前台、断开设备时，迟到结果只记录而不执行。
7. 事件接口留空先确认本机记录；随后接朋友实际事件存储 URL，断网重试并核对 `record_id` 去重和数据库保存确认。不要使用图片 `/analyze` 代替事件接口。

安装步骤见 [安装说明](安装说明_0.6.2.txt)，BLE 和事件字段见 [接口约定](接口约定.md)，朋友可直接填写 [视觉后端接入清单](给视觉后端同学的接入清单.md)。

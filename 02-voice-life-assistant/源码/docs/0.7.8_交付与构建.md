# 0.7.8 安装、源码与复现

交付文件：根目录 `语音生活助手_0.7.8_调试版.apk`、`语音生活助手_0.7.8_Android完整源码.zip` 和 `语音生活助手_0.7.8_文件校验.txt`。APK 包名 `cn.seniorvoice.demo`，版本 `0.7.8` / `19`，minSdk 26、targetSdk 34、compileSdk 35；这是内部调试包，不能作为应用市场正式发布包。

## 安装和第一次连接

在原手机覆盖安装，不先卸载，以保留联系人和设置。该 APK 的 v2 签名已核验，证书 SHA-256 为 `b1c0147d65e4fd519f915fb6305e4c42d72598ba328c84634196f33403cbcf34`，与现有项目旧版一致。

1. 打开首页“设置”，按“准备基础权限”完成蓝牙授权；旧 Android 还需定位权限和定位开关。
2. 点击“搜索附近设备”，选择自己的硬件，等到“硬件已就绪 · 可双向收发”。勾选自动重连，并确认后台连接已开启。
3. 在华为应用启动管理允许助手自启动、关联启动和后台活动，保留常驻通知。此后可回桌面或进入其他 App，不需要每次回原生调试页连接。
4. 要在其他 App 前台执行打开应用、拨号或 B 单步操作，还需开启本 App 无障碍服务并保持手机解锁。B 截图观察需用户同意、开始本次观察；不会因自动连上硬件就自动恢复截图授权。

硬件必须继续 BLE 广播并使用可重新找到的设备地址；重连有退避和系统扫描等待，不能保证开机立即连接。系统“强行停止”、撤权和厂商禁止后台会阻止自动恢复。延迟排查见 [后台连接与语音延迟排查](0.7.8_后台连接与语音延迟排查.md)。

## 完整 Android 源码

ZIP 内为 `SeniorVoiceDemo-0.7.8/` 项目目录，包含 `app/src` 全部 Kotlin/Java、Manifest、资源、HTML、Vosk 模型及许可、单元测试、`app/libs` 的本地依赖、Gradle Wrapper/构建配置、文档和本轮电脑检查证据。归档含逐文件 `SOURCE_MANIFEST.sha256`。

不包含本机 SDK/JDK、Gradle 缓存、`local.properties`、私有签名密钥、第三方 API Key、旧安装包和构建中间产物。源码中的服务器配置模板令牌为空；手机实际配置需从测试手机确认。历史 README 提及的独立后端部署目录不属于 Android 源码包，已有后端单独交付物仍在原工作区。

## 构建与电脑验证

使用 Android Studio 或 JDK 17、Android SDK Platform 35、Build Tools 35.0.0、Gradle 8.9。设置本机 `ANDROID_HOME`，或由 Android Studio 生成本机 `local.properties` 指向 SDK。联网首次同步会获取 Android Gradle Plugin 8.7.3、Kotlin 2.0.21 和测试依赖。

```powershell
./gradlew.bat :app:assembleDebug :app:compileDebugUnitTestKotlin :app:lintDebug
./scripts/test-ble.ps1
```

`test-ble.ps1` 直接运行已编译 JUnit，兼容当前中文 Windows 路径；在其他开发目录也可以使用标准 `./gradlew.bat :app:testDebugUnitTest`。APK 输出到 `app/build/outputs/apk/debug/app-debug.apk`。其他电脑默认调试证书不同，重新构建的 APK 不能保证覆盖原安装；原项目调试密钥未包含在源码中。

可选页面桥接检查需本机 Node.js、Playwright 和 Edge；安装依赖后执行 `node scripts/test-dashboard.mjs`，也可把 Playwright 包绝对路径作为参数。此检查使用 mock Android 桥，不能替代手机 WebView/蓝牙/无障碍实测。

# 0.8.0 更新与验收

本版版本名 `0.8.0`、versionCode `21`，包名仍为 `cn.seniorvoice.demo`，由 `0.7.9 / 20` 升级。可使用相同签名覆盖安装以保留设置；构建和打包后的实际 APK、签名及校验以本版交付证据为准。

## 本次更新

- **A 快路径**：明确的打开应用、拨打已保存联系人、返回/桌面/最近应用优先走手机本地能力。普通指令无需等千问。模糊姓名仍需确认；不会按识别文字猜测音频来自 A 或 B。
- **A 自然语言**：其余问题可通过独立“A 智能指令”设置接入自有代理 `/v1/commands/interpret`，提交文字及本次真实目录，接收一个意图；需要操作时先确认，页面变化或确认过期即取消。视觉问题继续走已有 OCR/物体服务。A 和 B 分工、设置及确认流程保持独立。
- **权限准备与修复**：权限向导检查蓝牙、通知、电话、无障碍和后台准备，并提供系统设置入口。应用不能代替用户点击系统授权；华为后台活动还需在系统中允许。缺权应显示具体原因和修复入口。
- **连接与进度**：首次在设置中选择真实设备；记住设备并开启自动重连后，硬件再次广播时尝试恢复连接。首页显示当前录音、传输、转文字和处理阶段，完整日志通过设置中的“查看联调日志”查看。离开首页应由后台服务继续收包。

手机只配置自有服务器令牌。真实硅基流动 Key 只放 Render 环境变量。A 代理更新与验收说明见 [服务端 AI 指令部署](0.8.0_服务端AI指令部署.md)；现有视觉服务设置仍参照 [视觉服务接入](0.7.9_服务接入与同音联系人.md)。

## 验证边界

A 的语音确认、同音联系人选择和澄清补充需要固件回传本次 `a_clarification.prompt_id`，详见本版部署交接。旧固件、裸 WAV 和 v1 文字帧不带该字段时，仍可发起完整指令，但不能用一段无关联的“确认”批准旧操作；请使用手机弹窗按钮。不能把本版 APK 的协议支持写成固件已经实现。

本说明不宣称真实华为 Mate30 5G、ESP32、Render 或真实模型已经验收。电脑编译、单元测试、mock 页面与代理测试均不能代替真实 BLE、ASR、网络、摄像头、TTS 或系统后台验证；以 `release/0.8.0/evidence/` 实际存在的本版输出为准。代理源码已补测试不等于部署完成，`/healthz` 成功也不等于模型推理成功。

本次最终构建成功：250 项 JVM 测试、43 项 mock 浏览器检查和 19 项代理 mock HTTP 测试通过；lint 无 Error/Fatal，保留 47 项 Warning；APK 签名校验通过，包名 `cn.seniorvoice.demo`、版本 `0.8.0 / 21`。这些是电脑验证结果，八项真实设备验收仍全部待执行。

## 八项实机验收（逐项记录，当前待执行）

1. **权限**：安装后按向导授权；拒绝一次蓝牙或电话权限，确认提示明确且修复后可继续。无障碍和华为应用启动管理由本人开启，手机保持解锁。
2. **后台连接和延迟**：首次选定设备并开启后台连接、自动重连；进入微信后重启眼镜，检查重连、双向收发和 A/B 来源标签。记录录音结束、首包、末包、ASR 完成各时间，区分传输与识别耗时；再测断线半包不执行。
3. **A 本地控制**：从真实 A 分别说“打开微信”“打开 QQ”（换成两款真实已安装 App）；核对实际前台。说“返回上一页”“返回桌面”，核对本地操作和阶段提示，不要求调用云端。
4. **A 智能理解与确认**：部署新代理并配置 A 后说一条自然语言指令，检查真实 HTTP 和 task_id；确认后只做一步，取消、超时和页面变化均不执行。说关闭另一个非当前应用，必须澄清，不能直接回桌面。
5. **A 联系人**：使用 App 保存的测试联系人验证拨号；同音或多个候选时先确认，拒绝不拨号。缺电话权限时提示修复，号码不上传给模型。使用获同意的测试号码。
6. **A 视觉**：真实 A 各发起一次读文字和物体识别，眼镜拍摄本次图片、上传指定服务器，核对 answer 在手机显示并由手机 TTS 朗读；保留匹配的 task/frame 证据，不使用旧图冒充当前照片。
7. **B 帮助**：在允许截图的真实页面制造停留，取得真实模型建议；B 录音同意后只执行一步并停止。重新触发后拒绝，确认零操作；模型不能绕过确认控制手机。
8. **互斥及异常**：B 待确认时启动 A，旧 B 提示、回包和确认必须失效；分别断网、错误令牌、服务失败，检查有限时间内明确失败、可重试且没有旧任务误执行。离开 App 时重复 A/B 音频收包。

每项记录设备/固件与 APK 版本、实际服务器根地址（不写令牌）、时间、结果、去敏日志和失败原因。未执行填“待测”，失败填“失败”；不要把未验证功能写成已通过。

# OCR 结果弹窗（0.7.6）

本版在 0.7.5 源码上增加 OCR 结果弹窗，保留已有 A 文字帧、WAV 与 B 功能。包名不变，versionCode 17；不是直接覆盖修改旧的 0.7.4 APK 文件。

## 使用

进入“A/B 眼镜帮助 · 配置与状态 → A 文字与药盒识别”，保存真实 OCR 根地址和独立令牌，检查模型就绪，填写“生产日期是什么？”或“这上面写了什么？”，点击“选择 JPEG 测试识别（作为新 A 任务）”。服务返回有效结果后，前台首页或 A/B 设置页弹出“文字与日期识别结果”。

弹窗显示服务实际返回的回答、候选核对提示和识别证据；文字可滚动、选择，点击“知道了”关闭，不自动朗读。多个候选、未找到与不支持的结果沿用各自说明。OCR 请求失败或配置缺失会显示“文字识别未完成”，不会冒称成功。文件本身无效时仍由原状态提示反馈。

原来的页面状态、本机记录、BLE 文字回传保留。模型仍运行在设置指向的服务器或电脑，后端接口不变。选图测试不需要眼镜，也不需要开启 B 或无障碍。

## 前后台和取消

- 在首页或 A/B 设置页前台时，使用应用内对话框。
- 切到其他应用时，若助手无障碍服务已连接且手机未锁屏，使用结果浮窗，长文可滚动；OCR 浮窗等用户关闭，不再 20 秒自动消失。
- 无法显示窗口时，结果暂存在当前进程，返回首页或 A/B 设置页时显示；进程退出后通过原“记录”页查看。
- 新 A 或取消当前任务会清理旧弹窗和待显示结果，过期 OCR 回调仍由原任务校验拦截。
- OCR 浮窗显示期间暂停 B 的新停留采样，避免用 B 提问覆盖结果；关闭后重新观察。

## 真机验收

1. 不连接眼镜、不启用无障碍，从设置页选择真实 JPEG，确认收到有效结果后弹窗显示实际答案与原文。
2. 测试长原文、多个候选、未找到、请求错误，确认文本可滚动、按钮可见，不伪造日期。
3. 点“知道了”，确认不被后续状态刷新重复弹出；在“记录”中仍能看到结果。
4. 结果到达前切回首页、切换外部应用，分别检查应用内弹窗、无障碍浮窗及无无障碍时返回应用显示的路径。
5. 新 A、取消、断线后旧结果不得弹出；长文浮窗存在时 B 不覆盖它。

电脑编译和检查不能替代上述手机验收，也不能证明当前 OCR 服务模型已经就绪。

# 0.7.2 功能与验证

验证时间：2026-10-24；Windows 本地离线构建。主工程版本 0.7.2 / versionCode 13，包名 cn.seniorvoice.demo。

## 已完成

- 队友 B Agent 源码接入现有单个无障碍服务、B BLE 录音元信息、Vosk 离线识别与弹窗。
- 保留本地截图停留触发；开启 Agent 后不再依赖旧 Render `/vision/analyze` 判断才可询问。用户给出目标后才请求独立配置的视觉语言模型。
- 按目标提出一次明确点击，用户针对该次问题说“对”才重新核对窗口、控件树、页面内容并分发一次点击；模型比较前后图后停止。
- A 启动销毁旧 B Agent、取消请求/录音识别/候选；A 结束不恢复旧候选。锁屏、停止观察、断开服务、配置变化清理任务。
- B 模型 URL、模型名、令牌、调试 LAN 选项在设置中；OCR URL/令牌仍可编辑，LAN 地址示例为 http://192.168.1.17:8001，没有写为固定运行时默认值。
- release 清单禁止 HTTP，运行时 URL 校验也使用 release BuildConfig.DEBUG=false 拒绝 HTTP；旧调试偏好不能绕过。模型请求禁止重定向；HTTP 错误不显示响应正文；日志隐藏各服务令牌。
- 原有 A/B、OCR 与旧建议模式保留。第三方来源、许可与本地适配说明已保存，许可也随 APK assets 分发。

## MobileAgentB 的现有输出格式边界

本次复用已交付的 MobileAgentB，没有改造为接收任意“澄清 JSON”的新 Agent。自建代理应保留 OpenAI-compatible chat 响应：单个 `choices`、`assistant` 角色、`finish_reason: "stop"`，不返回 tool calls。截图使用 `image_url`，值为 `data:image/jpeg;base64,...`。

规划正文须依次返回 `### Thought ###`、`### Plan ###` 两节；点击提议须依次返回 `### Thought ###`、`### Action ###`、`### Description ###` 三节，Action 严格为 `{"action":"click","target_id":整数}`，且编号必须来自本次真实允许控件。坐标由手机依据控件计算，不采用模型自由生成的坐标。协议校验实现在 `app/src/main/java/com/mobileagent/app/api/BModelProtocol.kt`。

当前目标询问、拒绝与纠正由手机 B 状态机处理，尚不支持任意 `{"clarification":"..."}` 形式的模型返回。格式无效、找不到可靠控件或用户未确认时停止；不能把自由文本推测成点击。只有当前提示的用户确认才允许一次操作，A 抢占后旧响应和旧确认均失效。

## 固件最少需要对齐的内容

1. 按 [BLE PCM 补充协议](BLE_PCM补充协议_0.7.8.md) 明确 `source_button`、`session_id`、`task_id`、`event_id`；B 还须回传最新 `prompt_id`，不得按识别文字猜按钮。A 按下即发 `button_start`，才能在录音结束前清理 B。
2. 当前新增的是 `recording_meta → audio_start → audio_chunk → audio_end` JSON PCM 契约，格式 `pcm_s16le`，带采样率、声道、位深和纯 PCM 长度。若固件已有其他二进制 PCM 帧，交付实际帧定义与抓包后才能对接。旧无标签 WAV、v1/en 文字仅保留 A 兼容。
3. 固件完成 BLE 订阅后允许手机回传 ACK/capture；音频块不逐块等待应用 ACK。手机返回 ready/started 后按 BLE 可发送能力连续有序传输，见延迟排查文档。
4. 视觉 capture 区分硬件 `task_id` 与 `vision_task_id`，携带 `frame_id` 和限时上传凭证；固件拍摄本次 JPEG，通过 Wi-Fi PUT 上传到指定 URL。不能上传历史图或把 JPEG 重新塞入 BLE。
5. 断线/取消/A 抢占后丢弃旧 B；新录音使用新 event_id。上传凭证和录音内容不输出到公开串口或共享日志。

## 上手机后的最短准备

1. 覆盖安装当前 APK，保持同包同签以保留已有设置。首次准备中允许蓝牙；旧 Android 扫描还需要定位权限和定位开关。按需授予电话、通知和无障碍权限。
2. 在整合首页“设置”中搜索并选择自己的硬件，看到“可双向收发”；确认“自动重连已记住的设备”和后台连接已开启。首次选择之后，日常无需进入原生调试页重新连接。
3. 华为“应用启动管理”中允许自启动、关联启动、后台活动。先切回桌面测试常驻接收，再测试其他 App 前台。后台打开 App、拨号和 B 页面操作还需开启助手无障碍服务、保持手机解锁；不要用系统“强行停止”模拟普通切后台。
4. 在 A/B 高级设置中先测试手机中文朗读。声音来自手机 TTS；服务器返回的是结构化文字结果，不是默认给眼镜播放的音频。
5. B 需启用页面帮助与 B Agent，打开无障碍，并同意截图分析、开始本次页面观察。重启 App 后重新开始观察；恢复 BLE 连接不会自动恢复截图同意。
6. 云端未完成时先验 BLE→ASR→本地打开 App。OCR 可先用“服务器通路测试”选真实 JPEG；这仅验证手机与服务器，不替代眼镜拍照和朗读验收。

# 0.7.0 功能与验证

基于用户提供的 0.6.2 APK 对应源码修改，保留原包名、联系人、历史记录和签名。用户文件与工作区旧 APK 的 SHA-256 一致：D8A6DE19785BE44A1A7DC6BC9328B7FDD4219D346363C1403B82D46A4EF62AFB。

## 实现内容

- A：明确语音打开本机已安装应用、拨打本 App 保存联系人；实物问题请求眼镜拍摄对应 task/frame，再用本张 JPEG + 原问题调用现有 /analyze。真实问答质量受现有后端能力限制。
- B：每约 2 秒采样普通手机页面，32×32 灰度图同时比较初始帧与相邻帧，默认持续 25 秒，结合页面包名/窗口/控件判断停留；超过 6 秒没有有效样本重新计时，缓慢滚动不会只靠相邻帧相似而累积为停留。
- 达到停留条件后调用 /vision/analyze；仅真实云端分析且返回帮助内容时显示“需要我的帮助吗？”。按 B 的回答离线识别，完整拒绝语结束，简短同意追问目标，具体目标重新获取手机截图交给 /analyze，显示建议。当前 B 不自动点击。
- A 的 button_start 到达即使 B 世代失效，取消 B 窗口、ASR 和 HTTP；迟到结果、已失效 prompt、来源错误的录音和旧照片均不得用于新任务。A 完成后重新观察，不恢复旧 B。
- BLE、离线 ASR 和任务路由移到进程级运行时，前台服务保持连接，不因 HomeActivity 切换或销毁主动断开。常驻通知可停止全部任务。系统终止进程和厂商后台限制仍可能中断。
- 录音按按钮、用途、会话、任务及问题编号路由，接收前持久去重，ASR 使用独立文件，取消后的任务不回调执行；上一段 B 不允许按 A 重放。A/B 结果保留本机记录。
- B 默认关闭；需开启无障碍并开始本次截图观察。截图不落盘，停留比较在本机，视觉请求才上传 JPEG；敏感/输入/锁屏等页面拒绝。本次同意不跨进程重启。

## 兼容与边界

旧裸 WAV 仅兼容 A；B 和录音开始立即抢占要求固件按新版协议发送元信息。手机 APK 不能自行辨别两个物理按键。此次未修改 ESP32 固件、GPIO 或四路舵机驱动。

现有后端 OpenAPI 不包含完整任务型手机操作 agent。此版适配 /vision/analyze 和 /analyze，B 提供建议而不连续操作，/analyze 的通用实物回答仍需验证。服务处于 mock、无帮助内容或失败时 B 不弹窗。A 实物照片还需板端上传并返回任务专属、同服务 HTTPS JPEG 地址，不能靠共享“最近照片”接口完成关联。

旧手动 AI 单步练习保留独立设置，A 优先；BLE COMPLETE 不再触发旧单步流程。紧急定位通知、自动发消息、支付和跨账号同步未实现。

## 电脑验证与现场验收

构建、静态检查、JVM 测试、签名和版本数据见同目录《0.7.0交付校验》。新增测试覆盖 A 抢占各 B 状态、旧任务取消、prompt 只回答一次、重新计时、缓慢滚动、元信息约束、裸 WAV 开始/结束时序、模拟视觉拒绝、拒绝共享最近照片地址和已取消网络任务不启动。

尚未连接华为手机、ESP32 或四路舵机，没有真实云模型调用或图片问答端到端验收。现场应验证：A 打开应用/拨号；跨 App 后再次按 A；B 普通页面停留并弹窗；B 拒绝、追问、具体目标；B 等待/录音/网络请求期间分别按 A；旧 B 和旧照片回传不生效；切页、锁屏、断线、通知停止服务都清理任务。步骤见《安装说明_0.7.0.txt》。

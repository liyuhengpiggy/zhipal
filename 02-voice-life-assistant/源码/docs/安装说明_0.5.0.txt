语音生活助手 0.5.0 手机安装说明

1. 把同包 APK 用微信“文件传输助手”发到 Android 手机。打不开时，在手机文件管理中解压这个 ZIP，点击 APK 安装。
2. 已有本项目旧版本请直接覆盖安装，不要先卸载，以便保留联系人。支持 Android 8.0 及以上。安装包约 83 MB，建议预留 500 MB 空间。
3. 打开助手，点“申请电话权限（只授权，不拨号）”，允许。保存一个称呼，例如“女儿”，及真实测试电话号码。无需读取手机通讯录。
4. 在手机安装抖音完整版。双卡手机在系统中先设置默认通话 SIM。
5. 先测试“打开抖音”；回到助手，文字输入“给女儿打电话”再测试。这会实际呼出，没有 App 二次确认。
6. 设备连接设置填写硬件提供的 Service / Notify / Write UUID，搜索连接，并允许蓝牙权限。
7. 硬件发送录音 WAV 后，手机自动离线转文字并执行。第一次需等待内置模型准备，不用联网下载。反馈使用震动与页面文字。
8. 推荐硬件发送 16 kHz / 16 bit / 单声道整数 PCM WAV，从 RIFF 文件头开始按顺序发送完整字节，不用 JSON 或 Base64。每次 Notify 遵守 BLE MTU。
9. 保持手机解锁、助手在前台；打开抖音或拨号后先回到助手，再测试下一条指令。
10. “后端记录存储”地址可以暂留空，不影响本地识别执行。不要填图片 /analyze。朋友需要另提供事件保存接口，详见“接口约定.md”。

本版本已完成编译、签名校验和 39 项 JVM 自动测试，另做过 Windows 合成语音模型测试。尚未连接你们真实手机及 ESP32，不能保证识别准确率或声称真机联调完成。

系统初次授权、双卡选择和厂商安全提示仍可能出现。离线模型可能听错，请先用测试号码验证。手动重新识别会再次执行，包括再次拨号。

更详细的每一步和排错方法请看同包“0.5.0手机安装与联调.md”。

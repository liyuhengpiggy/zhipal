## 接入结论

推荐 `implementation("com.bagent:assistant-feature:1.3.0")`，在主进程 Application 中 configure，再从前台 Activity openSetup 完成系统授权。源码模块接入也是已构建路径。不同 applicationId 的 Maven 二进制宿主与 release 混淆构建均通过，必要权限和组件合并已经静态核查；46 项本地测试通过，SDK Lint 0 错误/3 警告，二进制宿主 0 错误/2 警告。

最终主工程未提供，设备未连接，不能承诺合并后零错误或免授权直接运行。已交付的是可接入的功能库、依赖元数据、可编译宿主和明确验收步骤。系统无障碍、悬浮和录屏同意仍需用户完成。

## APK 选择

- 原 1.3 性能优化版：维持用户当前体验的独立运行基线。
- 模块化集成示例：同 applicationId com.bagent.sample，versionCode 5 / versionName 1.3-sdk1；使用新的 SDK 服务名，覆盖升级后需重新开启新无障碍服务并授权录屏。
- 二进制宿主验证：org.example.assistanthost，release 开启 R8，但使用 debug 签名且没有真实模型配置；它证明二进制接入，不应当作已配置好的成品助手。

模型仍为 SiliconFlow Qwen/Qwen3-VL-32B-Instruct。模型访问客户端代码在最终 APK 内，32B 模型权重在云端。SDK AAR 和模板不携带真实 Key，主软件需要自己的配置。

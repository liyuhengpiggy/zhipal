# SDK 公开接口速查

包名：com.bagent.assistant。优先用 AssistantFeature，避免业务代码依赖 Service.instance 的生命周期。

| 接口 | 调用约束 | 说明 |
|---|---|---|
| defaultCloudConfig(apiKey): ApiConfig | 构造配置 | 默认原 32B 模型、单次短输出、1152/JPEG78、40 秒单请求 |
| configure(context, modelConfig, allowHostApplication=false) | 主线程、空闲时；每次主进程启动配置 | 相同配置可重复调用；忙碌时换配置会抛 IllegalStateException，不会中途替换请求 |
| isConfigured(): Boolean | 查询当前进程配置 | 不等于账号余额、网络或模型服务已经实测可用 |
| openSetup(activity) | 主线程、当前可见 Activity | 打开 SDK 权限和状态设置页 |
| status(context): Status | 主线程 | 返回真实系统开关、服务连接、配置、截图等分项状态 |
| installModelClientFactory(factory?) | 主线程、空闲时 | VlmApiClient 替换点；null 恢复默认客户端 |
| installScreenshotProvider(provider?, isReady) | 主线程、空闲时 | 共享宿主截图，宿主保留 Bitmap 所有权，SDK 复制；null 恢复默认录屏方案 |
| suspendForHostTask() | 可挂起，内部切 Main | 在 A 开始前 await；取消并等待 B 的协程、废弃待确认 |
| resumeAfterHostTask() | 主线程 | A 结束后恢复接受新求助，不重放旧动作 |
| stop(context) | 可挂起，内部切 Main | 清理 SDK 任务、本地投屏和浮层；不撤销系统无障碍授权，不停止宿主共享投屏 |

Status 字段：configured、accessibilityEnabled、accessibilityConnected、overlayGranted、captureReady、iconRunning、busy、hostTaskActive、sharedCapture。所有值只表示调用时刻；系统可能稍后终止服务或投屏。

## 与主工程集成时的约定

1. 同一主进程管理配置、截图 callback、Activity 和 Service。
2. 配置/截图来源/模型客户端不能在 B 忙碌时切换；先 await suspendForHostTask，完成操作后在 finally 恢复。
3. A/B 控制权由一个宿主调度器管理。suspendForHostTask/resumeAfterHostTask 不是可重入计数锁，不要多个业务模块交叉调用、嵌套调用或未等待就开始任务。
4. provider 必须可取消、返回完整当前帧，不阻塞主线程；宿主不能同时 recycle SDK 正在复制的图。
5. 在主线程发起恢复；取消路径使用 NonCancellable + Dispatchers.Main.immediate 的 finally。
6. 自定义模型客户端仍必须遵守 target_id 契约。调用层替换不授予系统权限，也不会绕过点击前的 guard。

## 已保留的底层接口

- com.bagent.android.AndroidAssistPort：适合宿主已经有自己的无障碍与完整生命周期调度时接入；需要调用方提供 AccessibilityService、截图函数、VlmApiClient、Main CoroutineScope。
- observe / suggest / dispatchOnce / reflect / release：Observation 持有的图片由 port 管理，必须 release。dispatchOnce 开始前会同步校验，只支持一个明确点击。reflect 会额外请求模型，新浮层流程不使用它。
- com.bagent.android.BAssist：原语音/B 按钮状态机适配入口，配合 task/prompt/sourceButton 契约；不是新浮层门面的替代同名类。不得同时把事件送给两套会执行动作的流程。

最终软件若已经有一个必须复用的 AccessibilityService，推荐开发者评估底层接入并建立统一调度，而不是机械再开两套无障碍服务。当前交付的现成 feature 提供独立 SDK 服务路径；底层复用模式需要对宿主代码做适配，无法在没有主工程的情况下自动完成。

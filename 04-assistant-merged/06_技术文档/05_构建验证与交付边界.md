## 本轮没有完成或不能代替的内容

- 没有最终主 APK 工程，不能证明与其业务、已有服务、权限策略和版本依赖已完全兼容。
- 本机 adb 没有连接手机，设备测试仅编译，没有运行。不能把 46 项本地测试称为 46 项鸿蒙端到端测试。
- 不同包名的二进制宿主证明依赖与静态合并成立，不证明权限已授予或实际点击已验收。
- release 使用 debug 签名只是集成验证；没有配置你们的正式签名，也没有上架部署。
- 原 1.3 的合成模型请求验证是小样本、非手机端到端。没有用它承诺真实应用成功率或固定秒级响应。
- Android 15/16、任意 targetSdk 升级、主 APK 已有 AccessibilityService 的底层复用方案，都需要按实际工程补验。

## 合并完成的判定

建议主工程至少达到以下状态再交付使用：同一依赖实现只存在一份；实际 merged manifest 正确；Application 每次启动完成配置；权限拒绝与重授正确；截图来源唯一；A/B 任务不同时抢屏；系统停止投屏后正确恢复；待确认取消/过期/换页不执行；正常确认只执行一次；正式签名和 release 混淆在目标手机验收。

这些是对用户“合成一个 APK 后可以直接使用”的具体实现与验收条件。SDK 已提供相应功能和示例，系统授权与最终设备行为仍无法在交付包里自动完成。
